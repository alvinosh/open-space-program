# T303: Parts can go on a capsule's side

Found on 2026-11-12 while capturing T272: a thermometer in hand pointed at a C-1 Capsule shows no
place to go and does not go on; on a tank's side it does. A capsule drawn by a model seems to offer no
surface to put things on, so instruments, RCS blocks and antennas can only go on procedural parts. In
KSP they go on pods.

## Done when

- In a capture, an instrument and an RCS block go on a C-1 Capsule's side and stay there through a
  launch.
