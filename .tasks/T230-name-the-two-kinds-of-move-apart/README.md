# T230: Name the two kinds of move apart

Dragging a part takes it off and puts it on somewhere else (T216). The Move tool slides it along
where it sits (T206). Both are moving, and the tool's name suggests the drag.

## Scope

- Rename the tool for what it does (Offset or Slide), in the bar, its tooltip and the hint.

## Done when

- The bar, tooltips and hints use one word for each, and neither is "Move" for both.
