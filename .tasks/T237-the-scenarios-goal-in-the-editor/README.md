# T237: The scenario's goal in the editor

Coming from a scenario, the player builds without seeing what the craft has to do.

## Scope

- The scenario's goal and what it asks of the craft (where to, crew, return) in the vessel column,
  with the delta-v it needs (T235).

## Done when

- Opening the editor from a scenario shows its goal there.

## Where it comes from

From the editor review of 2026-11-07: the user asked for everything wrong with the editor from a UX point of view, then for each finding to be filed as a task. The epic, T221, lists them all.
