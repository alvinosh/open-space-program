# T270: Repairs and spare parts

Realistic only, with failures. The crew of a vessel can fix a malfunction, which takes time and spare
parts (a resource with mass). A critical failure cannot be fixed. Parts outside the cabin need a walk
outside, which is shelved (T065); until then only parts inside can be fixed, a guess to confirm.

## Done when

- A failed scrubber is fixed from inside, uses its spares, and works again (test).
- A critical failure offers no repair.

## 2026-11-10

Spacewalks will be done (the user). This task is the repairs from inside; parts outside are fixed on a
spacewalk in T283, once EVA (T104) is in.
