# T226: The parts list stays while a part's settings show

Adding parts is a long loop: take one from the list, click it, its settings take the list's place,
change them, go back with Parts, find the place in the list again, take the next.

**Ask the user first:** this goes against T207, which put the settings in the left rail in place
of the list at their request (2026-11-06).

## Scope

- The parts list stays on the left; the picked part's settings show on the right, in the column
  that now holds only the vessel's height, mass and part count.
- The vessel's figures and Launch stay in that column, above and below the settings.

## Done when

- Parts can be added and set one after another without the list going away.

## Where it comes from

From the editor review of 2026-11-07: the user asked for everything wrong with the editor from a UX point of view, then for each finding to be filed as a task. The epic, T221, lists them all.
