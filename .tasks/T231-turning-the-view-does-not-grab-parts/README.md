# T231: Turning the view does not grab parts

A left drag on a part takes it off at once; on nothing it turns the view. Close in on a big craft
most of the screen is parts, so most drags meant to turn the view grab a part, and a drag on the
root carries the whole craft.

## Scope

- Turn the view with a right drag as well (as KSP does), or only grab a part that is already
  picked. Decide which when building it; keep undo for both.

## Done when

- With the craft filling the screen the view can be turned without moving a part.

From the editor review of 2026-11-07: the user asked for everything wrong with the editor from a UX point of view, then for each finding to be filed as a task. The epic, T221, lists them all.
