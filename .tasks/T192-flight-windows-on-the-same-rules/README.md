# T192: Flight windows and toolbar on the same rules

T185 covers the menus and the editor. The flight HUD has the same problem to a lesser degree.

## Scope

- Bring the theme's 17 font sizes down. The readouts on the navball and altimeter keep their large figures.
- Window buttons (`step_button`, `context_item`, `danger_button`) onto `btn` and its variants.
- The toolbar has 17 buttons, and Structure and Communications share an icon. Fold rarely used windows into a smaller set, keeping key bindings.

## Done when

- The user has reviewed captures of the flight view and map and accepts them.
