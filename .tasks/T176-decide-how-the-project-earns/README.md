# T176: Decide how the project earns

Decided 2026-11-01: the game stays free; there is no per-build price. Write the plan down and keep to it.

## The plan

1. The game, free, on GitHub and itch. A free Steam listing is optional (reach and Workshop, no price).
2. Supporters (Ko-fi, GitHub Sponsors). Perks that never gate play: credits and a plaque, dev builds a week early, votes on which pad or mission comes next, a badge on servers. The donate page says donating unlocks nothing; that is honest but gives no reason to give.
3. Multiplayer v1, free and self-hosted: a dedicated server, a server list, a shared persistent universe (T138).
4. Managed servers, monthly: a private persistent universe for a friend group, club or class. Price it from a measured number (CPU of a headless server with a few active vessels, plus support, backups and payment fees), not a guess. Listing deals with existing game-server hosts give one-click install at no running cost (check their terms).
5. Education: classroom servers with mission packs. Ask a few teachers first.

## What to expect

- The best-known free competitor says in a press release of 23 July 2026 that community contributions cover about 2% of its development costs. Donations are a tip jar. The income is supporters plus hosting, both scaling with the player count: enough for servers and some time, unlikely to pay a salary at first. Sponsors (space and education organisations) and grants are the open options if that is not enough later.
- Selling hosting needs multiplayer that works, and anyone can self-host an open-source server, so the product is convenience, uptime, backups and support. Expect few paying servers at first.

## Do not

- Add pay-to-win, a paywall on the editor or on parts, or a store or cosmetic currency.
- Sell servers before the multiplayer is stable.

## Done when

- This plan is accepted or changed, and the donate page and the website roadmap say the same thing.
