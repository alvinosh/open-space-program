# T233: Refusals name parts and offer the fix

Refusals speak in part ids and ask for things the editor cannot do: "`tank_2` is the root: reroot
before taking it away". The player never sees ids, and there is no reroot in the editor.

## Scope

- Refusals the player sees use part names ("the lower tank" or its name).
- Where there is a fix, offer it as a button (Make this the root, with T234).

## Done when

- No refusal shown in the editor contains a part id.

## Where it comes from

From the editor review of 2026-11-07: the user asked for everything wrong with the editor from a UX point of view, then for each finding to be filed as a task. The epic, T221, lists them all.
