# T280: Mission planner in the editor

Run the craft's systems forward with the same simulation, in a place the player picks (an orbit of a
body with its sunlight and shadow, a surface, a cruise between planets) for a time and a crew they
pick: what runs out when, power in sun and shadow, dose, data sent, and the parts whose failure would
end the mission.

## Done when

- The planner's figures for 30 days in lunar orbit match flying it at warp, to rounding (test).
- It names a single point of failure on a craft with one power source.
