# T019: Editor UI

Layouts and data keys for the editor, in the game's own data-driven UI.

## Scope

- Palette window: search, tags, size filter, drag a part onto the scene.
- Part properties generated from the parameter schema: sliders with units and ranges, a list of engines, of tank types, of what a tank holds.
- Numbers window, checks window (click one to select the part), file menu.
- Sequences: the staging window's drag and drop applied to the draft's sequences.
- Keys for rotate, symmetry, undo and redo, delete, duplicate, camera views; tooltips.

## Done when

- A person builds a two-stage rocket with the mouse, and every number on the screen is the one the flight uses.
