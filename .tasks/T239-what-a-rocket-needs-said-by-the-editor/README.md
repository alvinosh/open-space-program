# T239: What a rocket needs, said by the editor

A new rocket starts as an empty grid and a parts list. Nothing says what a rocket needs to fly.
T173 is the tutorial; this is what the editor itself says, tutorial or not.

## Scope

- With an empty or unfinished craft, the checks (T236) say what is missing: something to control
  it, propellant, an engine, a way to come down.
- A Start from a basic rocket choice beside New rocket (pod, tank, engine) to change from.

## Done when

- A craft missing one of those says so, and the basic rocket launches and reaches space.

## Where it comes from

From the editor review of 2026-11-07: the user asked for everything wrong with the editor from a UX point of view, then for each finding to be filed as a task. The epic, T221, lists them all.
