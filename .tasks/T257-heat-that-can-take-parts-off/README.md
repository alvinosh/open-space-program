# T257: Aerodynamic heating that takes parts off, by material

Any part can overheat and come off, each to the limit of what it is made of, with heat conducted
between joined parts, and heating that holds up from ascent speeds to entry. Engines and sunlight
add heat. The player can see what is hot.

## Done when

- A fin burns off on entry while the shielded capsule survives, in a test.
- A part's limit follows its material, and the entry smoke tests still pass.
