# T067: Rendering

Clouds, plumes, ocean, particles, reflections, viewports, ray-traced IVA.

## The reference mods

`references/` (local only, in `.gitignore`) holds five graphics mods for another game, as the bar to clear: T182 and T184 (Scatterer's sky, eclipses and flare), T119 (its ocean), T117 and T184 (EnvironmentalVisualEnhancements), T183 (Firefly), T118 (Waterfall), T122 (Deferred).

Read them for what they do and how it looks; write our own from the published methods. This project is MIT or Apache-2.0, and Scatterer, Deferred and Firefly are GPL-3.0 (Firefly's art All Rights Reserved) and Waterfall CC BY-NC-SA. Only EnvironmentalVisualEnhancements is MIT, and even that has a GPL part. No code, shaders or assets from them go in here.
