# T241: Undo and redo buttons

Undo and redo are Ctrl+Z and Ctrl+Shift+Z only, and nothing says what was undone.

## Scope

- Undo and redo buttons in the bar, greyed out when there is nothing to undo or redo, with what
  they would undo in the tooltip ("Undo: move fin").

## Done when

- Both buttons work, grey out at the ends of the history, and name the change.

## Where it comes from

From the editor review of 2026-11-07: the user asked for everything wrong with the editor from a UX point of view, then for each finding to be filed as a task. The epic, T221, lists them all.
