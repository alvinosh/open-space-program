# T227: A part just put on is picked

A part put on is not picked, though it is usually the one the player wants to set next (a tank
sized to what it joins). Picking it was taken out because the popup then opened on every
placement; with the settings beside the list (T226) it costs nothing.

## Done when

- Putting a part on picks it, its settings show, and the parts list stays.

## Where it comes from

From the editor review of 2026-11-07: the user asked for everything wrong with the editor from a UX point of view, then for each finding to be filed as a task. The epic, T221, lists them all.
