# T249: A small stock parts list and casual stock rockets

Choose the short list a new player sees: a few engines, pods and tanks with original names. Rebuild
the stock craft, scenarios and tutorials on it, each one flown by a script as before.

The rockets are balanced for the smaller Solar System (T251).

On the base game's fuel (2026-11-09), tanks sized for hydrogen or methane hold far more mass, so
some stock craft no longer work: Heron has a thrust-to-weight of 0.5 at liftoff and cannot leave the
pad, and Colossus is at 1.0 and barely can. Scenario text still names real propellants ("Hydrolox
core stage").

## Done when

- Every stock craft flies its scenario on the short list, in the base game alone.
