# T240: Feedback in one place

What the editor says turns up in four places: the hint in the lower right corner, a notice under
Launch, a problem line in the rail, and refusals under Launch.

## Scope

- What the pointer is doing (hints, refusals while dragging) shows by the pointer or at the foot
  of the view.
- What is wrong with the craft goes in the checks list (T236).

## Done when

- Each message has one place, and no message about the pointer's work is in a side column.

## Where it comes from

From the editor review of 2026-11-07: the user asked for everything wrong with the editor from a UX point of view, then for each finding to be filed as a task. The epic, T221, lists them all.
