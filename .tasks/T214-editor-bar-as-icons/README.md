# T214: Editor bar as icon buttons

Asked for on 2026-11-06, in one list of what is wrong with the editor: "the left hand side parts
menu is just full of text and not intuitive at all, there is overlap issues, also 5 buttons at the
top, all with text, not intuitive at all, also when you click on a part a menu comes up, we should
use the left hand side parts menu and display the information there [...] i want to be able to grab
a part and move it [...] we also need to add symetry modes, mirror modes, part clipping by
different offets, like 1degree 5degreee 20 degree 45 ect. And we should use icons where we can."
That list is T207 and T212 to T218.

The bar over the left panel is six text buttons: Back, Vessels, Parts, and the Shape / Move / Turn
group. Nothing says what each does until it is pressed, and the tools' keys (1, 2, 3) are not shown.

## Scope

- Icon buttons (T212), grouped: leave (back), what is shown (vessels, parts), tools (shape, move,
  turn), then undo and redo, symmetry (T217) and snap (T218) as they come.
- A tooltip on each with its name and key; the tool that is on is lit.
- The bar sits where nothing covers it, the same in every editor state.

## Done when

- The bar is icons only, each with a tooltip, and a capture shows the tooltips and the lit tool.
