# T238: Keys on the buttons, and a controls overlay

Most of the editor is on keys and hidden gestures (Q/E, X, R, C, 1 to 3, Delete, right click to
put back, middle drag and WASD to move the view). The only teaching is a small hint in a corner.

## Scope

- Each bar button shows its key.
- A ? button (and key) that lists the editor's controls over the view.

## Done when

- Every editor key can be found on screen without hovering.

## Where it comes from

From the editor review of 2026-11-07: the user asked for everything wrong with the editor from a UX point of view, then for each finding to be filed as a task. The epic, T221, lists them all.
